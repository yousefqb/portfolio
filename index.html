Case Study • Database Development

SQL Server Database Architecture & Query System

Problem

Many application databases suffer from poor normalization, leading to duplicate records, slow multi-table joins, and a lack of audit tracking when critical business records are modified.

Solution

I designed and implemented a relational database schema normalized to 3NF in Microsoft SQL Server. The database uses stored procedures for transactional safety, views for reporting, triggers for auditing, and indexes to speed up query filtering.

My Role

I personally handled the entire design and implementation: creating the ERD table relationships, writing T-SQL scripts for table creation and constraints, programming stored procedures and triggers, and creating clustered and non-clustered indexes.

Tech Stack

Microsoft SQL Server • T-SQL • Stored Procedures • Views • Triggers • Indexing

Key Features

  • Normalized Relationships: 3NF schema preventing data redundancy across business entities.
  • Parameterized Procedures: Encapsulated transactional queries that guard against SQL injection.
  • Audit Logging Triggers: Real-time automated history tracking on critical table modifications.
  • Index Tuning: Added clustered and non-clustered indexes on frequent filter columns to improve query efficiency.

What I Learned

This project gave me hands-on experience in how database design directly affects application maintainability. I learned how execution plans work, why indexing must be targeted carefully, and how stored procedures ensure clean separation between database logic and application code.

Case Study • Frontend Application

DevPalette & TaskFlow Suite

Problem

Developers and designers often need quick utilities like generating color codes and tracking small day-to-day tasks without opening heavy desktop software or complex websites.

Solution

I built a lightweight, responsive browser application that brings together a dynamic color palette generator with one-click clipboard copying and a persistent task management list in a clean interface.

My Role

I designed and built the full application using vanilla JavaScript, HTML5, and CSS3. I implemented the DOM manipulation logic, event listeners, clipboard API integration, and local storage state persistence.

Tech Stack

JavaScript (ES6+) • HTML5 • CSS3 • DOM API • LocalStorage API

Key Features

  • Color Generator: Real-time color generation with instant hex code copying to clipboard.
  • Task Manager (CRUD): Create, read, mark complete, and delete tasks seamlessly.
  • Local Persistence: Saves user tasks in the browser via LocalStorage so data stays after refreshing.
  • Responsive Layout: Fully responsive interface designed for both mobile and desktop screens.

What I Learned

Building this without third-party frameworks gave me a deep understanding of core JavaScript fundamentals, DOM event handling, asynchronous clipboard APIs, and clean client-side state persistence.
